## 前言

2022年11月30日，总部位于旧金山的OpenAI公司公开发布了ChatGPT——这款风靡全球的AI聊天机器人能够像人类一样生成内容、回答问题并解决复杂任务。上线仅两个月，ChatGPT的月活跃用户数便突破1亿，创下消费级技术应用史上最快的用户增长纪录（截至目前）。ChatGPT本质上是一款基于OpenAI GPT-3.5系列大语言模型（LLM）经指令微调与对话优化的聊天机器人产品。我们将在后续章节中详细解析这些核心概念。

### **注意**

无论是否使用 LangChain 构建大语言模型应用，都需要依赖大语言模型作为核心组件。本书的代码示例将统一采用 OpenAI API 作为大语言模型服务提供商（其平台已列明具体定价）。使用 LangChain 的优势之一在于，读者既可采用 OpenAI，也可选择其他商业或开源的大语言模型提供商来复现所有示例。

三个月后，OpenAI 正式开放 ChatGPT API，使开发者能够调用其对话与语音转文本功能。这直接催生了海量新应用与技术探索，它们被统称为 *生成式人工智能*。

在正式定义生成式AI与大语言模型之前，我们先来谈谈*机器学习*（ML）的概念。有些计算机*算法*（可以想象成一套可重复执行的“配方”，用于完成特定任务，比如整理一副扑克牌）是由软件工程师直接编写的。而另一些算法则是通过海量训练样本*学习*得来的——此时软件工程师的工作重心从编写算法本身，转向编写能够生成算法的训练逻辑。机器学习领域的许多研究都聚焦于开发预测类算法，其应用场景包罗万象：从明日天气预测，到亚马逊司机的最优配送路线规划。

随着大语言模型及其他生成式模型（例如用于生成图像的扩散模型，本书不涉及此类）的出现，同样的机器学习技术如今被应用于生成新内容的任务中——比如生成一段全新的文本或画作——这些内容既具备独特性，又基于训练数据中的示例进行构建。大语言模型尤其是一种专门用于生成文本的生成式模型。

大语言模型与以往的机器学习算法相比，还有另外两点不同：

- 它们基于海量数据进行训练；从头开始训练这类模型成本极高。

- 它们用途更广泛。

同一个文本生成模型可用于摘要、翻译、分类等多种任务，而以往的机器学习模型通常专为特定任务训练和使用。

这两点差异共同导致软件工程师的工作重心再次转移，他们需要投入越来越多的时间来研究如何让大语言模型适配具体应用场景。这正是 LangChain 的核心使命所在。

到 2023 年底，竞争性大语言模型相继涌现，包括 Anthropic 的 Claude 和谷歌的 Bard（后更名为 Gemini），进一步拓宽了这些新能力的获取渠道。随后，数千家成功创业公司和大型企业纷纷集成生成式 AI API，构建了覆盖客户支持聊天机器人、代码编写与调试等多样化场景的应用程序。

2022年10月22日，Harrison Chase在GitHub上发布了LangChain开源库的首个提交。LangChain的诞生源于一个核心洞察：最具价值的大语言模型应用，往往需要将LLM与“其他计算或知识源”结合使用。例如，你可以尝试让大语言模型回答这样一个问题：

```
How many balls are left after splitting 1,234 balls evenly among 123 people?
```

你可能会对其数学能力感到失望。然而，如果将其与计算器功能结合使用，你可以转而指示大语言模型将问题重述为计算器能够处理的输入形式：

```
1,234 % 123
```

接着，你可以将其传递给计算器函数，从而得到原始问题的准确答案。LangChain 是首个（在撰写本文时也是规模最大的）提供此类构建块及可靠组合工具以构建更大规模应用的库。在探讨如何利用这些新工具构建引人注目的应用之前，我们先来深入了解 LLM 和 LangChain。
