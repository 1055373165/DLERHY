1. 高层目标

当前主线已经不再是 runtime self-heal backend 继续扩写，而是：

- 让 translate agent 在 `PDF 书籍 / EPUB 书籍 / PDF 论文` 上具备可证明的高保真翻译 readiness

当前主线 = `translate-agent 高保真整本文档翻译 readiness` + `受控 slice-first 放量能力`

3. 当前 benchmark 边界

虽然 overall 已经是 `go`，但边界必须保持清楚：

- 认证范围只覆盖当前 `9` 个 benchmark 样本
- 高风险 text PDF 现在已经能走正式 guarded bootstrap path，不再需要 direct parser probe 旁路
- `L2 / L6` 的部分图片 slice 仍然依赖高分辨率 fallback render；当前已经能区分“向量页/不可抽原图页”“非 canonical 的 fragmented composite figure”以及“真正的原图 parity 缺口”
- `L6` 的认证语义是 `Tier C`：优先保证内容与 artifact 保真，并在必要时显式降级，而不是伪装成完全版式无损
