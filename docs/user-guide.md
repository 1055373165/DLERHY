# 使用指南

把一篇英文网页或一本英文书（PDF、EPUB）翻译成可以直接阅读的中文版。本指南按第一次使用的顺序写：配服务商 → 粘贴链接或上传 → 开始（或自动开始）→ 阅读。

界面只有三处：左侧导航的「首页」（粘贴链接、上传、最近的书）、「需要你处理」（所有书里等你做决定的事）、「设置」（阅读偏好和模型服务商）。每本书有自己的页面：顶部一句话说明现在的状态和唯一的下一步，下面是「进度」「阅读」等标签。

## 1. 配置模型服务商（第一次使用）

左侧导航「设置」→「模型服务商」→「添加服务商」：

| 字段 | 填什么 |
|---|---|
| 类型 | 「OpenAI 兼容接口」。「Echo」只用于离线测试，不会真的翻译 |
| 接口地址 | 服务商的 OpenAI 兼容地址，例如 `https://api.deepseek.com/v1` |
| 模型 | 模型名，例如 `deepseek-v4-flash` |
| API key | 服务商给你的 key。保存后不会再显示；编辑时留空表示沿用已保存的 key |
| 最大输出 token | 单次调用最多输出多少 token，默认值一般够用 |
| 单价 | 美元 / 百万 token，分输入、缓存命中、输出三项。填了才能在翻译前估算花费、在运行中统计花费和执行预算 |
| 关闭思考模式 | DeepSeek 等推理模型建议勾选。不勾的话，模型可能把输出额度全用在思考上，运行会暂停 |

保存后点「测试连接」确认 key 可用，再点「设为当前」。之后新开始的翻译都用这个服务商，不需要重启。

还没有可用的服务商时，首页会提示先去设置，粘贴链接和上传暂时不能用。已经因为缺服务商而暂停的翻译，在你配好服务商后会自动接着进行，不用再点继续。

## 2. 粘贴链接或上传书稿

「首页」→ 粘贴英文网页链接 →「翻译这个网页」；或选择 `.pdf` / `.epub` 文件 →「上传并翻译」。完成后直接进入这本书的页面。

扫描版 PDF 会走 OCR，解析时间更长。部署没有安装 OCR 组件时（例如默认 Docker 镜像），上传扫描版会直接提示，请改传文字版 PDF 或 EPUB。

**翻译网页时。** 服务器会把页面连同样式一起保存下来（外链样式表和网页字体内嵌，图片和链接指向原网站），之后和书稿一样翻译、审校。

- 结果是「中文网页」：原页面的排版、配色、字体、图片都不变，只把文字换成中文；正文里的链接、加粗、斜体保留在原来的位置。
- 抓取时会去掉页面脚本，所以依赖脚本的动画、交互控件、动态加载的内容不会出现在译文里。正文完全由浏览器脚本生成的网站（部分单页应用）、需要登录的页面无法抓取，会直接提示。
- 图片里的文字（例如图表）不翻译。
- 请只翻译你有权翻译的网页，译文的传播仍受原网站版权约束。

## 3. 自动开始与费用预估

导入后，如果这本书预计最多花费不超过你设的「自动开始上限」（默认 $1，在「设置 · 阅读偏好」里改；设为 0 表示每次都先确认），翻译会直接开始，书页顶部写明预估并提供「停止翻译」。预估金额按服务商设置的单价计算；一篇文章的用量大约只有一整本书的十分之一，所以常见情况是文章直接开始、整本书先让你确认。

否则书页停在「开始翻译（约 $x）」按钮上，并写明原因：预估超过上限，或服务商没有填单价、估算不出金额（这种情况永远不会自动开始）。按钮下面同时显示预计 token 用量。

- 预估基于一次真实整书运行测得的比例，误差约 ±30%。
- 没有计入提示缓存折扣，所以输入部分通常偏高，实际花费一般落在区间偏下的位置。
- 参考：一本 1429 句、11 章的技术书，用 deepseek-v4-flash 实测输入约 319 万、输出约 21 万 token，耗时约 25 分钟。

## 4. 翻译进行中

整本书会经过：确定术语 → 翻译 → 审校 → 生成中文版。书页「进度」标签列出每一步和最近动态。

**快速阅读模式**（默认开启，开关在「开始翻译」按钮旁和「设置」里）：术语直接锁定，不停下来等你确认；锁定的术语事后可在书页「术语与决策」标签里修改或解锁。关闭后，遇到需要锁定的术语会停下来等你批准。

**需要你处理时。** 书页顶部和左侧「需要你处理」会列出等你的事（待批准的术语、只有你能解决的暂停），可以就地批准或处理；浏览器标签页标题也会显示数量。翻译可能因为下面这些原因暂停，书页会写明原因和下一步：

| 原因 | 怎么办 |
|---|---|
| 服务商账户余额不足 | 充值后点「继续翻译」 |
| API key 被拒绝 | 在「设置」里更新 key，然后继续 |
| 思考模型把输出额度用完了 | 在服务商设置里勾选「关闭思考模式」或调大最大输出 token，然后继续 |
| 达到预算上限 | 请管理员调高上限（组织月度预算：`PUT /v1/orgs/{org_id}/budget`），然后继续 |
| 连续多次调用失败 | 通常是服务商暂时不可用，稍后继续 |

继续时会从停下的地方接着翻译，已经完成的部分不会重做。服务进程意外退出（包括被强制结束）后，重启服务，未完成的运行会自动接着跑。

## 5. 阅读与下载

**直接阅读。** 翻译完成后书页出现「阅读中文版」；以后再打开这本书会直接进入「阅读」标签。可在「中文版 / 中英对照 / Markdown / PDF」之间切换（网页还有「中文网页」，默认打开它；书名旁「原网页 ↗」回到英文原页）。Markdown 可以点「看源码」；「下载」下载当前格式。某个格式第一次打开时会先生成，可能要等一两分钟。只有部署装了 PDF 渲染组件时才会出现 PDF。

**下载。**

「首页」→「全部书」→ 书名右侧「下载 ▾」：

| 选项 | 内容 |
|---|---|
| 中文版 · HTML | 单个 HTML 文件，图片已内嵌，带目录，浏览器直接打开 |
| 中文版 · EPUB | 电子书，适合 Apple Books、多看、Kindle（经转换）等阅读器 |
| 中文版 · Markdown | 下载为 zip：Markdown 文件和它引用的图片 |
| 中文版 · PDF | 由中文版排版打印成的 PDF（需要部署安装 PDF 渲染组件） |
| 中英文对照版 · HTML | 单个 HTML 文件，逐段中英对照，适合校对和学习 |
| 中文网页 · 原排版 | 仅网页：保留原页面布局的中文网页，单个 HTML 文件（字体和样式已内嵌，图片从原网站加载） |

书名和章节标题会翻译成中文（例如 “CHAPTER 3” 显示为「第3章」）。

## 6. 预付额度

组织按预付额度使用：先充值，翻译按实际用量扣费（服务商单价 × 平台定价倍数）。

- 左下角显示「预付余额」；「下载本月用量明细（CSV）」列出每本书的用量和扣费。
- 开始翻译前，如果这本书的预估花费可能超过余额，预估下方会提示。
- 余额用完时，新的翻译不能开始，正在进行的会暂停；充值后点「继续翻译」接着翻译，已完成的部分不会重复扣费。
- 预付模式下，服务商必须填写单价，否则不能开始翻译。

## 7. 常见问题

**翻译到一半能关掉浏览器吗？** 可以。翻译在服务端运行，与浏览器无关。

**能换服务商接着翻吗？** 可以。暂停后在「设置」里把另一个服务商「设为当前」，再点「继续翻译」；之后的部分用新服务商翻译。

**为什么估算和实际花费不一样？** 估算不计提示缓存折扣，并且模型每次输出的长短有差异。以左下角预算条和用量明细记录的实际用量为准。

**表格为什么整体翻译？** 表格作为一个整体交给模型翻译，保证行列对应；在逐句对照视图里，表格对应的是整张表，而不是单个句子。
