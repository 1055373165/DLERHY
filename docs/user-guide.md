# 使用指南

把一本英文书（PDF 或 EPUB）翻译成可以直接阅读的中文版。本指南按第一次使用的顺序写：配服务商 → 上传 → 看预估 → 开始 → 下载。

## 1. 配置模型服务商（第一次使用）

左侧导航「服务商」（MODELS）→「添加服务商」：

| 字段 | 填什么 |
|---|---|
| 类型 | 「OpenAI 兼容接口」。「Echo」只用于离线测试，不会真的翻译 |
| 接口地址 | 服务商的 OpenAI 兼容地址，例如 `https://api.deepseek.com/v1` |
| 模型 | 模型名，例如 `deepseek-v4-flash` |
| API key | 服务商给你的 key。保存后不会再显示；编辑时留空表示沿用已保存的 key |
| 最大输出 token | 单次调用最多输出多少 token，默认值一般够用 |
| 单价 | 美元 / 百万 token，分输入、缓存命中、输出三项。填了才能在翻译前估算花费、在运行中统计花费和执行预算 |
| 关闭思考模式 | DeepSeek 等推理模型建议勾选。不勾的话，模型可能把输出额度全用在思考上，运行会暂停 |

保存后点「测试连接」确认 key 可用，再点「设为当前」。之后新开始的翻译都用这个服务商，不需要重启。

还没有配置服务商时，书库和上传照常可用；点「开始整书转换」会提示先去「服务商」页配置。

## 2. 上传书稿

「工作台」→ 选择 `.pdf` 或 `.epub` 文件 →「上传并解析」。解析完成后能看到章节数（CH）、翻译分包数（PKT）和句子数（SENT）。

扫描版 PDF 会走 OCR，解析时间更长。

## 3. 看费用预估

解析完成后，「开始整书转换」按钮下面会显示这本书预计要用多少 token；如果当前服务商填了单价，还会给出美元金额区间。

- 预估基于一次真实整书运行测得的比例，误差约 ±30%。
- 没有计入提示缓存折扣，所以输入部分通常偏高，实际花费一般落在区间偏下的位置。
- 参考：一本 1429 句、11 章的技术书，用 deepseek-v4-flash 实测输入约 319 万、输出约 21 万 token，耗时约 25 分钟。

## 4. 开始翻译

点「开始整书转换」。整本书会经过：术语表 → 全文翻译 → 审校 → 导出。进度在「运行」页查看。

**暂停与继续。** 运行可能因为下面这些原因自动暂停，「运行」页会写明原因和下一步：

| 原因 | 怎么办 |
|---|---|
| 服务商账户余额不足 | 充值后点「继续当前转换」 |
| API key 被拒绝 | 在「服务商」页更新 key，然后继续 |
| 思考模型把输出额度用完了 | 在服务商设置里勾选「关闭思考模式」或调大最大输出 token，然后继续 |
| 达到预算上限 | 请管理员调高上限（组织月度预算：`PUT /v1/orgs/{org_id}/budget`），然后继续 |
| 连续多次调用失败 | 通常是服务商暂时不可用，稍后继续 |

继续时会从停下的地方接着翻译，已经完成的部分不会重做。服务进程意外退出（包括被强制结束）后，重启服务，未完成的运行会自动接着跑。

## 5. 下载

「书库」→ 书名右侧「下载 ▾」：

| 选项 | 内容 |
|---|---|
| 中文版 · HTML | 单个 HTML 文件，图片已内嵌，带目录，浏览器直接打开 |
| 中文版 · EPUB | 电子书，适合 Apple Books、多看、Kindle（经转换）等阅读器 |
| 中文版 · Markdown | 下载为 zip：Markdown 文件和它引用的图片 |
| 中英文对照版 · HTML | 单个 HTML 文件，逐段中英对照，适合校对和学习 |

书名和章节标题会翻译成中文（例如 “CHAPTER 3” 显示为「第3章」）。

## 6. 常见问题

**翻译到一半能关掉浏览器吗？** 可以。翻译在服务端运行，与浏览器无关。

**能换服务商接着翻吗？** 可以。暂停后在「服务商」页把另一个服务商「设为当前」，再点「继续当前转换」；之后的部分用新服务商翻译。

**为什么估算和实际花费不一样？** 估算不计提示缓存折扣，并且模型每次输出的长短有差异。以「运行」页和左下角预算条记录的实际用量为准。

**表格为什么整体翻译？** 表格作为一个整体交给模型翻译，保证行列对应；在逐句对照视图里，表格对应的是整张表，而不是单个句子。
